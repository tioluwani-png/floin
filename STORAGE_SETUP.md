# Supabase Storage Setup for PDF Reports

## Create Storage Bucket

1. Go to your Supabase Dashboard → Storage
2. Click "Create a new bucket"
3. **Bucket name**: `monthly-reports`
4. **Public bucket**: ✅ Yes (PDFs need to be shareable)
5. **File size limit**: 50MB (more than enough for PDFs)
6. **Allowed MIME types**: `application/pdf`
7. Click "Create bucket"

## Set Storage Policies (Optional - for extra security)

If you want to restrict who can upload (only service role):

```sql
-- Allow service role to upload
create policy "Service role can upload PDFs"
on storage.objects for insert
to service_role
with check (bucket_id = 'monthly-reports');

-- Allow public to download PDFs
create policy "Public can download PDFs"
on storage.objects for select
to public
using (bucket_id = 'monthly-reports');
```

## Test PDF Generation

### Option 1: Manual API Test

```bash
curl -X POST "https://your-app.vercel.app/api/cron/monthly-reports?month=2026-06&business=YOUR_BUSINESS_ID" \
  -H "Authorization: Bearer your_cron_secret"
```

### Option 2: Generate in Code

```typescript
import { generateMonthlyReportPDF, uploadPDFToStorage } from '@/lib/whatsapp/pdf-generator'

// Generate for last month
const lastMonth = '2026-05'
const businessId = 'your-business-id'

const pdfBuffer = await generateMonthlyReportPDF(businessId, lastMonth)
const pdfUrl = await uploadPDFToStorage(pdfBuffer!, businessId, lastMonth)

console.log('PDF URL:', pdfUrl)
```

## Verify Storage

After running the cron or manual test:

1. Go to Supabase Dashboard → Storage → monthly-reports
2. You should see folders for each business ID
3. Inside each folder: `YYYY-MM-report.pdf`
4. Click to download and verify the PDF looks good

## Troubleshooting

### "Bucket does not exist" error
- Make sure you created the `monthly-reports` bucket
- Check bucket name is exactly `monthly-reports` (lowercase, hyphen)

### "Permission denied" error
- Verify `SUPABASE_SERVICE_ROLE_KEY` is set correctly in env vars
- The service role key bypasses RLS, so it should always work

### PDF generation fails
- Check all database tables have data for the month
- Verify @react-pdf/renderer is installed: `npm list @react-pdf/renderer`

### PDF doesn't render properly
- Open the generated PDF and check for errors
- The PDF should have: business name, revenue, sales by channel, withdrawals, debts

## What Happens on 1st of Month

1. **Cron triggers** at 7am UTC (8am WAT)
2. **Generates PDFs** for all active businesses (last month's data)
3. **Uploads to Supabase Storage** (permanent storage)
4. **Sends WhatsApp message** with download link to all business users
5. **Users forward** the professional PDF to accountants, partners, investors
